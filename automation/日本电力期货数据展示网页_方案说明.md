# 日本电力期货数据统计展示网页 · 方案说明

> 面向对象：投资经理客户（非技术背景）
> 文档用途：说明本项目要做什么、怎么用、数据从哪来、如何长期维护

---

## 一、项目目标

为投资经理团队搭建一个**可在线访问的网页**，用于：

- **统计**日本电力期货市场的关键数据（价格、成交量、持仓量等）
- 以**图表形式可视化**展示，让客户一眼看懂市场变化
- 帮助客户把握电力期货的波动规律，辅助投资决策

客户无需安装任何软件，打开浏览器、输入网址即可查看，数据**每天自动刷新**，无需人工干预。

---

## 二、核心功能

### 1. 数据看板（首页）
- 以卡片 + 图表形式，集中展示最新一期的核心指标
- 例如：最新结算价、当日涨跌、成交量、持仓量、市场热度等
- 重点数据高亮显示，便于快速扫读

### 2. 历史趋势
- 支持查看任意时间区间（如近 7 天 / 30 天 / 90 天 / 自定义）
- 提供折线图、柱状图等多种视图，直观对比价格与成交变化
- 可切换不同合约或指标，进行横向比较

### 3. 每日自动更新
- 系统每天在固定时间（如收盘后）自动抓取最新数据并入库
- 网页打开时默认展示截至昨天的最新数据
- 更新过程全自动，客户无需任何操作；如遇异常会发出提醒

---

## 三、数据来源与更新方式说明

| 项目 | 说明 |
| --- | --- |
| **数据来源** | 日本电力期货交易所公开行情数据 / 权威金融数据接口（如交易所官网、合规数据供应商） |
| **数据类型** | 电力期货合约价格、成交量、持仓量、结算价及基础市场指标 |
| **更新频率** | 每个交易日结束后更新一次（默认每日自动执行） |
| **更新方式** | 服务器端定时任务自动拉取 → 清洗整理 → 存入数据库 → 网页读取展示 |
| **历史存储** | 每日数据自动归档，形成可回溯的历史库，支撑趋势分析 |
| **数据安全** | 仅使用公开/授权数据，不做任何交易操作，仅作展示用途 |

> 说明：若客户已有指定的数据供应商或内部数据源，可对接替换，更新逻辑保持不变。

## 四、网页结构概览

```
日本电力期货数据平台
│
├── 首页 / 数据看板
│   ├── 核心指标卡片（最新价、涨跌幅、成交量等）
│   └── 市场概览图表
│
├── 历史趋势
│   ├── 时间区间选择（7天 / 30天 / 自定义）
│   ├── 价格走势图
│   └── 成交量 / 持仓量对比图
│
├── 合约对比（可选）
│   └── 不同合约或指标横向比较
│
└── 关于 / 数据说明
    ├── 数据来源与更新时间
    └── 使用须知与免责声明
```

- **访问方式**：客户通过专属网址在电脑或手机浏览器打开
- **权限**：可设置访问密码或指定客户白名单，保障数据仅对授权客户可见
- **响应式**：自动适配电脑、平板、手机屏幕

## 五、交付与维护说明

### 交付内容
- 一个可在线访问的网址（网页平台）
- 管理员后台（用于查看更新状态、配置数据源）
- 本方案说明及使用手册（简明版）

### 维护方式
- **日常更新**：系统自动完成，无需客户参与
- **状态监控**：每日更新结果可查；失败自动告警并自动重试
- **技术支持**：提供定期巡检与问题响应（可按需约定服务周期）
- **可扩展**：后续可增加更多指标、预警提醒、导出 Excel / PDF 报告等功能

### 客户须知
- 本网页仅用于**数据展示与统计分析**，不构成任何投资建议
- 数据以公开/授权来源为准，最终以交易所官方发布为准
